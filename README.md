# Pizza-Menu
This project is a dynamic and responsive pizza menu webpage built using HTML, CSS, and JavaScript. It includes functionality to fetch pizza data from an API and render it on the page.

## Live Demo
https://raheeqmousa.github.io/Pizza-Menu/

## Technologies Used
- **HTML**
- **CSS**
- **JavaScript**

## Features
- **Fetches pizza data dynamically from an external JSON or API**

- **Displays pizza name, description, and price in a styled layout**

- **Responsive and clean design using pure HTML/CSS**

- **Simple structure, easy to extend**
